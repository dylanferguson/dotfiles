# Thresholds and citations

Every row cites a page on <https://practicaltypography.com>. Read the page for
the reasoning — it is not reproduced here.

Ranges are ranges. Butterick gives conditions for departing from most of them,
so treat a value outside a range as a question to ask, not a defect to file.

## Body text — audit and report these first

| Rule | Threshold | Page |
| --- | --- | --- |
| Point size | 10–12 pt print, 15–25 px web | `point-size.html` |
| Line spacing | 120–145% of point size | `line-spacing.html` |
| Line length | 45–90 characters | `line-length.html` |
| Font choice | Prefer a professional font over a system font | `font-recommendations.html` |

## Paragraphs and layout

| Rule | Threshold | Page |
| --- | --- | --- |
| First-line indent **or** paragraph spacing, never both | Indent 1–4× point size, or 4–10 pt of space | `first-line-indents.html`, `space-between-paragraphs.html` |
| Hyphenation | On when text is justified, off when ragged | `hyphenation.html`, `justified-text.html` |
| Centered text | Sparingly | `centered-text.html` |
| Letterspacing | 5–12% when setting caps or small caps | `letterspacing.html` |
| Kerning | On | `kerning.html` |

## Punctuation and symbols

| Rule | Threshold | Page |
| --- | --- | --- |
| Quotation marks | Curly, not straight | `straight-and-curly-quotes.html` |
| Apostrophes | Curly, always downward | `apostrophes.html` |
| Foot and inch marks | Straight marks, and only here | `foot-and-inch-marks.html` |
| Sentence spacing | One space | `one-space-between-sentences.html` |
| Word spacing | Never more than one | `word-spaces.html`, `white-space-characters.html` |
| Hyphens and dashes | Hyphen, en dash and em dash are distinct | `hyphens-and-dashes.html` |
| Ellipses | The single character, not three periods | `ellipses.html` |
| Exclamation points | About one per three pages | `question-marks-and-exclamation-points.html` |
| Ampersands | Sparingly | `ampersands.html` |
| Trademark and copyright | ™ © ®, not (tm) (c) (r) | `trademark-and-copyright-symbols.html` |
| Nonbreaking spaces | After section and paragraph marks | `nonbreaking-spaces.html`, `paragraph-and-section-marks.html` |

## Web specifics

Butterick gives principles rather than numbers here. The habits he names: body
text set too small, headings set too large, system fonts, overbuilt navigation,
and large blocks of colour.

Pages: `websites.html`, `typewriter-habits.html`, `body-text.html`,
`headings.html`, `color.html`.
